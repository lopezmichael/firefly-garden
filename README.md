# Firefly Garden

A cozy, glowing logic puzzle: place fireflies to light every path of a night
garden. Light Up (Akari) rules with an eight-neighbor clue twist. Web portals
first, iOS later, one TypeScript codebase.

```bash
npm install
npm run check   # typecheck, tests, build, bundle budget
npm run dev     # game dev server
npm run e2e     # browser smoke test (Playwright)
```

- `Firefly Garden Project Plan.md`: the full vision
- `ROADMAP.md`: phases and gates
- `ARCHITECTURE.md`: layers and data flow
- `docs/references/rules.md`: exact rules and level format
- `CLAUDE.md`: how we work
